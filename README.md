# موقع فكترة التسويقي

ملفات ساكنة بالكامل: لا خادم تطبيقات، ولا قاعدة بيانات، ولا خطوة بناء.
ارفع محتوى هذا المجلد كما هو إلى جذر الاستضافة.

## البنية

```
index.html          اختيار اللغة، ويحوّل إلى العربية بعد ثانيتين
ar/                 النسخة العربية: index · docs · pricing
en/                 النسخة الإنجليزية
site.css  site.js   مشتركان بين اللغتين
robots.txt          يسمح لزواحف البحث بالذكاء الاصطناعي صراحةً
sitemap.xml         الصفحات الست وملف الأسعار، مع hreflang
llms.txt            ملخّص المنتج لنماذج الذكاء الاصطناعي
pricing.md          الأسعار في صيغة يقرأها الوكيل الآلي
_headers            رؤوس أمان لـ Netlify و Cloudflare Pages
```

## قبل الرفع — ثلاثة أشياء

1. **رقم الواتساب.** ابحث عن `971500000000` في `ar/index.html` و
   `en/index.html` واستبدله برقمك.
2. **البريد.** `hello@faktra.ae` مذكور في الصفحات وفي `llms.txt`
   و`pricing.md`. اضبطه أو غيّره.
3. **النطاق.** جميع عناوين `canonical` و`hreflang` و`sitemap.xml`
   تفترض `https://faktra.ae`. إن اخترت نطاقًا آخر، استبدله في كل
   الملفات:

   ```bash
   grep -rl 'faktra.ae' . | xargs sed -i '' 's/faktra\.ae/نطاقك.ae/g'
   ```

## الرفع

يعمل على أي استضافة ملفات ساكنة. الأسرع مجانًا: Cloudflare Pages أو
Netlify — اسحب المجلد إلى صفحتهم وانتهى الأمر. وعلى استضافة تقليدية
عبر FTP، ارفع المحتوى إلى `public_html`.

## بعد الرفع — أربع خطوات تجعلك تُفهرَس أسرع

1. **Google Search Console**: أضف النطاق، وأثبت الملكية، وأرسل
   `https://نطاقك/sitemap.xml`.
2. **Bing Webmaster Tools**: نفس الشيء. بينغ هو مصدر Copilot.
3. **تحقق من robots.txt**: افتح `https://نطاقك/robots.txt` وتأكد أنه
   يظهر. حجب الزواحف يمنع الاستشهاد بك في إجابات الذكاء الاصطناعي.
4. **اختبر البيانات المنظّمة**: ضع رابط الصفحة في
   [Rich Results Test](https://search.google.com/test/rich-results).

## الفحص محليًا

```bash
node verify-site.mjs
```

تسعون فحصًا: صحة البيانات المنظّمة، ووجود canonical وhreflang، وأن كل
رابط داخلي يصل، وألّا يتسرّب نص عربي إلى النسخة الإنجليزية، وألّا تبقى
عامية في النسخة العربية، وأن تبديل الأسعار يبدّل الأرقام لا يمحوها.

يحتاج `jsdom`:

```bash
ln -s ../faktra-ui/node_modules node_modules
```
